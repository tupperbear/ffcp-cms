## Setup
1. Clone repo
2. Create .env file and add the following:
```
DIRECTUS_SECRET="<YOUR_SECRET_HERE>"
DIRECTUS_ADMIN_EMAIL="<YOUR_EMAIL_HERE>"
DIRECTUS_ADMIN_PASSWORD="<YOUR_PASSWORD_HERE>"

# Email details
EMAIL_FROM: "<EMAIL_ADDRESS>"
EMAIL_SMTP_HOST: "<EMAIL_HOST>"
EMAIL_SMTP_PORT: <EMAIL_PORT>
EMAIL_SMTP_USER: "<EMAIL_USER>"
EMAIL_SMTP_PASSWORD: "<EMAIL_PASSWORD>"

# Assets storage bucket
STORAGE_R2A_KEY: "<STORAGE_KEY>"
STORAGE_R2A_SECRET: "<STORAGE_SECRET>"
STORAGE_R2A_BUCKET: "<STORAGE_BUCKET>"
STORAGE_R2A_REGION: "<STORAGE_REGION>"
STORAGE_R2A_ENDPOINT: "<STORAGE_ENDPOINT>"

# Extensions storage bucket
STORAGE_R2E_KEY: "<STORAGE_KEY>"
STORAGE_R2E_SECRET: "<STORAGE_SECRET>"
STORAGE_R2E_BUCKET: "<STORAGE_BUCKET>"
STORAGE_R2E_REGION: "<STORAGE_REGION>"
STORAGE_R2E_ENDPOINT: "<STORAGE_ENDPOINT>"

```
3. Spin up the container
```
docker compose up
```
4. Access the application using the url output in the setup logs (http://0.0.0.0:8055)
